🛠️ 三、核心已完成之高階機制（勿再列為待開發）
==========================================

1. **RI (Reliance Index 信任指數) 與 GSI (全域相似度指數)**：
   - 已完成實體代碼計算。GSI 內建馬氏距離計算，並提供 Ridge 正則化與 Pseudo-Inverse（降級 pinv 矩陣）防禦，以應對特徵共線性與矩陣奇異黑天鵝。
2. **ISD 智慧熔斷攔截 (Intelligent Sampling Decision)**：
   - 當 GSI 連續警報（大於安全門檻 3.0）或常態空間偏離時，系統強制阻斷一切買進下單，實體代碼已全面完成並與 `simulate_agents` 和 `predict_today` 連接。
3. **9 大 Agent 個性化風險分級高勝率旁路（V5.3）**：
   - A1 / A4 / A7 (AGGRESSIVE) 旁路門檻勝率 `p_conj >= 0.70`；
   - A2 / A5 / A8 (MODERATE) 旁路門檻勝率 `p_conj >= 0.75`；
   - A3 / A6 / A9 (CONSERVATIVE) 旁路門檻勝率 `p_conj >= 0.80`；
   - 當勝率滿足各組別門檻且無 ISD 熔斷時，繞過一切型態過濾器，直接輸出 `action = "BUY", suggested_position = 1.0`。
4. **優化自適應三軌離場與均線遲滯保護（V5.3）**：
   - **軌道 1（硬停損）**：浮虧達到或超過 8% (`unrealized_pnl_pct <= -0.08`) 強制離場。
   - **軌道 2（過熱雙重確認）**：`z_bias >= overheat_z_bias` 且勝率跌破 0.60 時雙重確認成立，平倉離場；勝率強勢則續抱。
   - **軌道 3（趨勢轉弱離場 - 優化防洗盤）**：在均線上方（`z_bias >= -0.80`）時，允許勝率跌破 0.40 依然續抱（給予 0.41 假勝率保護緩衝），避免被短期洗盤震出；在均線下方（`z_bias < -0.80`）時，一旦跌破 `0.40` 則當天一擊平倉，拒絕 any 空頭磨損。
5. **LLM 軍師王謀決策診斷與一鍵閉環（V5.3）**：
   - Step 5 定性診斷，構建僅含 4 項必要數據的極簡 Prompt 實施 Context Pruning。
   - wang_mou_analysis 定性報告字數嚴格限制在 200 個繁體中文字以內。
   - 一鍵式 Pipeline 自動將競技場最優冠軍 ROI 及決策回饋至 LLM 定性裁決中，產出最終定性報告 `data/llm_agent_report.json`，全流程 100% 自動化閉環貫穿。
